## Goal

205 films in our database have only `edb` (Israeli Film Database) as their source — no film fund is recorded.  
For each film, find which Israeli film fund(s) supported it and record the evidence.

**Output file:** `/Users/moran/projects/israeli-movies-ind/data/film_funding_results.json`

## Sources to Check (in order)

### 1. Israeli Film Fund — filmfund.org.il
Search each title:
```
https://www.filmfund.org.il/Search?q=<film-title-in-hebrew>
```
Direct movie page (if ID known):
```
https://www.filmfund.org.il/Movie?movieId=<id>
```

### 2. NFCT (New Fund for Cinema & TV) — nfct.org.il
```
https://www.nfct.org.il
```
Look for "פרויקטים" / "סרטים נתמכים". Also try:
```
site:nfct.org.il "<film title>"
```

### 3. Rabinovich Foundation — rcy.co.il
```
https://www.rcy.co.il
```
Look for "קולנוע" / "פרויקטים נתמכים". Also try:
```
site:rcy.co.il "<film title>"
```

### 4. Gesher Film Fund — gesherfilmfund.co.il
```
https://www.gesherfilmfund.co.il
```

### 5. Makor Foundation — makorfilm.org.il
```
https://www.makorfilm.org.il
```

### 6. Jerusalem Film Fund — jff.org.il
```
https://www.jff.org.il
```

### 7. Fallback: Web Search + Hebrew Wikipedia
For each film still unfound after steps 1–6, search:
```
"<film title>" "קרן הקולנוע" OR "קרן רבינוביץ'" OR "הקרן החדשה" OR "קרן גשר"
```
Hebrew Wikipedia articles often list the fund in the infobox under **מימון** or **הפקה**.

## Output Schema

Write results to `/Users/moran/projects/israeli-movies-ind/data/film_funding_results.json`:

```json
[
  {
    "film_id": "edb:t0013690",
    "title_he": "אווה מריה",
    "year": 2016,
    "funds": ["filmfund", "nfct"],
    "fund_labels": ["הקרן הישראלית לקולנוע", "הקרן החדשה לקולנוע ולטלוויזיה"],
    "source_urls": ["https://www.filmfund.org.il/Movie?movieId=123"],
    "confidence": "confirmed",
    "notes": ""
  }
]
```

**Confidence values:**
- `confirmed` — fund page or Wikipedia infobox directly names the film
- `probable` — press article or interview names the fund
- `not_found` — no source found after all steps

Include every film in the output, even those with `"funds": []` and `"confidence": "not_found"`.
