We strive to update and implement the accessibility rules as much as possible, in accordance with the accessibility standards.\nThe website is optimized for level 2 (AA) accessibility of the W3C organization. In the following links you will find the website’s accessibility guidelines in **[Hebrew](https://www.isoc.org.il/files/w3c-wai/guidelines.html)** and in**[English](https://www.w3.org/TR/WCAG20/)**. The site was built according to W3C standards for CSS and HTML. The website is optimized to display in major browsers.  \n\n**Easily browsing the website**  \n\nYou can navigate forward in the site with the TAB button. To navigate backward, press the key combination: SHIFT + TAB.  \nBefore the main navigation of site, there is a hidden button that appears when it receives the keyboard focus. Clicking it will open a pop-up window. In the window, the site menu will appear. It can be closed by pressing the “ESC” button on the keyboard, or by clicking the “close” button in the menu. You can also navigate to it using the small keyboard arrows (up and down(.  \nYou can navigate from the main menu using “TAB” and “SHIFT + TAB”.  \nAt the top of the site there are buttons that can change the font size and the website colors, to facilitate viewing.\nTo assist in entering information into the website’s forms, there is a unique tool that enlarges the text as you type in the form fields. The tool opens and closes automatically when you are in a form field, and does not interfere with filling in the form.\n**Navigating areas**  \n\nThe site is divided into areas, such as the main content area and the versatile menu. At the start of each area, there is a level 5 heading indicating the name of the area you are in. Some of the headlines are also links, which allows you to skip that area and reach your desired content faster. For example, it is possible to skip over the main menu.\n**Using the keyboard for date display**\nLeft key on keyboard –shifts the keyboard’s focus to the previous day. The selection will move to the last day of the previous month, if the current day is the first of the month.  \nRight key on keyboard – shifts the focus to the following day. The selection will move to the first day of the next month if the current day is the last of the month.  \nUp key on keyboard – shifts the focus to the same day in the previous week. Continued typing in the same direction will transfer you to the same day in the previous month.  \nDown key on keyboard – shifts the focus to the same day of the next week. Continued typing in the same direction will transfer you to the same day of the next month.  \nPgUP – shifts the focus to the same day in the previous month. If the date is not available, the focus will be shifted to the last day of that month.  \nPgDn – shifts the focus to the same day next month. If the date is not available, the focus will be shifted to the last day of that month.  \nCtrl + PgUp – shifts the focus to the same day of last year. If the date is not available, the focus will be shifted to the last day of that month.  \nCtrl + PgUp – shifts the focus to the same day of the next year. If the date is not available, the focus will be shifted to the last day of that month.  \nHome – shifts the focus to the first day of the last month.  \nEnd – shifts the focus to the last day of that month.  \nTab / Shift + Tab – if the date display is in Modl mode, it can be navigated by selecting the closed/previous/next buttons. In any other case, go to the ‘related text’ boxes to choose from the date display.  \nEnter / Space – opens the text box to enter a date.\n**ARIA rules**\nIf you use a reading screen software or other assistive technologies, know that in this site Aria laws were taken into consideration.
