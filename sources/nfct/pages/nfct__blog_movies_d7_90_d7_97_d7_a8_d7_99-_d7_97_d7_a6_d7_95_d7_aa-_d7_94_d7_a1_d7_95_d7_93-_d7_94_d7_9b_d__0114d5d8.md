# אחרי חצות: הסוד הכי שמור בעיר
  * **תיעודי**
  * /
  * 3 פרקים * 45 דקות
  * /
  * 2020
  * /
  * ישראל
  * /
  * עברית


אלון קסטיאל, עבריין מין סדרתי פעל בחיי הלילה של תל אביב במשך עשור שלם באין מפריע. פוסט אחד בפייסבוק מצליח לפוצץ את הבועה והסכר נפרץ.
17 נשים מגישות תלונה נגדו במשטרה ולרגע נדמה כי הצדק עומד לצד הנפגעות אבל בהסדר הטיעון נותרו רק עבירות משניות. הוא נשלח ל-4.9 שנים בכלא בלבד, בניכוי שליש הוא ישתחרר עוד מעט.
**פסטיבלים ופרסים:**
תחרות פרסי הקולנוע הדוקומנטרי 2021.
**בימוי** : קרן שעיו
**הפקה** : מיקה תימור, יותם גנדלמן, בן גלעדי מפיקה שותפה: קרן שעיו
**חברת הפקה** : ביצתעין הפקות
**צילום** : מתן אקרמן
**עריכה** : שירה ארד
**עריכת פס קול** : ניל גיבס, ג'אנגל
**מוזיקה מקורית** : גל לב
**גופים תומכים** : הקרן החדשה לקולנוע וטלוויזיה, יס דוקו, מפעל הפיס
**עיצוב תמונה וצבע** : דימה לידחוב, אולפני אדיט
**עיצוב אפקטים ויזואליים** : אור דרורי
**תסריט** : קרן שעיו, שירה ארד
**כתוביות** : עברית, רוסית
