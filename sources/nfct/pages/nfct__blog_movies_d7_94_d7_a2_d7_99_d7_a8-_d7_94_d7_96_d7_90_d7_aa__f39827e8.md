# העיר הזאת
  * **עלילתי**
  * /
  * 80 דקות
  * /
  * 2023
  * /
  * ישראל
  * /
  * עברית


בעולם דמיוני, בזמן לא ידוע, בלילה סוער במיוחד שרה בנט (מוריה אקונס) מגיעה למשרד החקירות של הבלש ג'ו (עמית אולמן). היא מבקשת ממנו למצוא את אחותה שנעלמה.
בידיעה ששום דבר טוב לא יצא מזה, ג׳ו מסכים לפתוח בחקירה. מהר מאוד החקירה מסתבכת וג׳ו מוצא את עצמו לבד מול הפושע הכי מסוכן של ״העיר הזאת״.
**פסטיבלים ופרסים:**
Noir in Festival, מילאנו איטליה, 2023; תחרות Free Spirit פסטיבל הקולנוע הבינלאומי בוורשה, וורשה פולין, 2023; הפסטיבל הבינלאומי לסרטי סטודנטיות וסטודנטים, תל אביב ישראל, 2023.
**בימוי** : עמית אולמן
**הפקה** : חגי ארד, אהרון פאר, אלעד פלג
**חברת הפקה** : דרומהפקות בשיתוף תיאטרון האינקובטור
**צילום** : מישה פלטינסקי
**עריכה** : איל סיבי
**עריכת פס קול** : יוסי אפלבאום
**מוזיקה מקורית** : עומר מור, עמית אולמן, עומר הברון. מפיק מוזיקלי ומעבד: עומר מור
**גופים תומכים** : הקרן החדשה לקולנוע וטלוויזיה, קרן קולנוע מדרום, הקרן לקולנוע ישראלי, מפעל הפיס
**עיצוב תמונה וצבע** : אהרון פאר
**עיצוב אפקטים ויזואליים** : אריעד שיקנאג׳י
**עיצוב אמנותי** : ניצן ציפרוט
**משחק** : עמית אולמן, מוריה אקונס, ג׳ימבו ג׳יי, אלון נוימן, עידן אלתרמן, איציק פצצתי, ירמי (ג׳רמאיה) אומני. בהשתתפות: ראובן טדרוס, פלד, איתי זבולון (טונה), סימה ברמי, אקו מורגנשטן, דורון גוברמן, רביד פלוטניק, שירה אלתרמן, פטר קנולר
**תסריט** : עמית אולמן, עומר הברון (ג׳ימבו ג׳יי), עומר מור (איציק פצצתי)
**הפצה** : דרומהפקות
**כתוביות** : עברית, אנגלית
**שם הסרט באנגלית** : [The City](https://nfct.org.il/en/movies/the-city/)
